# 🚀 AlgoAI — AI Powered DSA Learning Platform

AlgoAI is an intelligent learning platform designed to help users improve their Data Structures & Algorithms (DSA) skills using **AI-driven insights and personalized recommendations**.

---

## 🧠 Features

- 📊 **User Progress Tracking**
  - Track solved & attempted problems
  - Store difficulty, topics, and time taken

- 🎯 **Weak Topic Detection**
  - Identifies weak areas based on:
    - Accuracy
    - Time taken
  - Helps focus on improvement areas

- 🤖 **AI-Powered Recommendations**
  - Suggests problems based on weak topics
  - Personalized learning path

- ⚡ **Code Execution Integration**
  - Run code directly using JDoodle API

- 📈 **Performance Analytics**
  - Visual insights into progress and strengths

---

## 🏗️ Tech Stack

### Frontend
- React.js / Next.js
- Tailwind CSS

### Backend
- Node.js
- Express.js
- TypeScript

### Database
- Supabase (PostgreSQL)

### APIs & Tools
- JDoodle API (Code Execution)
